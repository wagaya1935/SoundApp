# Sound App /音声・楽曲 共有サービス

## 概要
ユーザが自作の楽曲や音声を投稿・共有し、フィードバック(コメント・いいね)を受けてもっとより良い創作ができるようにするWebアプリケーションです。  
音声波形の可視化や、投稿したものにコメント機能を実装し、クリエイター同士の交流を促します。

## 開発背景
私自身、趣味でVOCALOIDを用いた楽曲制作を行っています。制作過程において、「このギターフレーズは良い」「このシンセサイザーのメロディは面白い」と、部分的なフレーズに魅力を感じることが多々ありました。

こうしたアイデアを自分だけで完結させず、他のクリエイターとも共有することで、より質の高い楽曲制作につなげたいと考え、本アプリを開発しました。作曲に行き詰まった際、このサービスが新たなアイデアを生むきっかけになれば幸いです。

## 主な機能一覧

### ユーザ向け
- 曲ファイルの アップロード / 削除機能
- 曲の いいね / タグ / コメントする詳細機能
- 曲の 検索機能(タイトル / タグ / 投稿者)
- メールアドレスとパスワードを利用した登録 / ログイン機能

### 非ユーザ向け (ゲスト向け)
- ログインしていないユーザも曲一覧 / 詳細(コメント)の閲覧可能
- 未ログインユーザが特定の操作(投稿など)をする時にログインを促す
- 曲の タイトル / タグ / 投稿者で検索可能
