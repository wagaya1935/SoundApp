# Sound App /音声・楽曲 共有サービス

## 概要
ユーザが自作の楽曲や音声を投稿・共有し、フィードバック(コメント・いいね)を受けてもっとより良い創作ができるようにするWebアプリケーションです。  
音声波形の可視化や、投稿したものにコメント機能を実装し、クリエイター同士の交流を促します。

- **Blade**
