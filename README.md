# Sound App /音声・楽曲 共有サービス

## 概要
ユーザーが自身の魅力的なフレーズや歌声合成ソフトによるカバーなど、形にする前の「好き」やアイデアを共有できる場、これらを幅広く公開・共有できるWebアプリケーションです。  
音声波形の可視化や、投稿したものにコメント機能を実装し、クリエイター同士の交流を促します。

## 開発背景
趣味で音声合成を使用した曲を制作してる中、魅力的なフレーズや歌声合成ソフトによるカバーなど、形にする前の「好き」やアイデアを共有できる場の必要性を感じ、これらを幅広く公開・共有できるWebアプリ「SoundApp」を開発しました。

こうしたアイデアを自分だけで完結させず、他のクリエイターとも共有することで、作曲に行き詰まった際、このサービスが新たなアイデアを生むきっかけになれば幸いです。

## 主な機能一覧

### ユーザ向け
- 曲ファイルの アップロード / 削除機能
- 曲ファイルの 再生 / 停止
- 曲の いいね / タグ / コメントする詳細機能
- 曲の 検索機能(タイトル / タグ / 投稿者名)
- 曲の投稿編集機能(タイトル / タグ)
- メールアドレスとパスワードを利用したアカウント登録 / ログイン機能
- アカウントの ログアウト / 退会機能
- アカウントの プロフィール編集機能 (アイコン / ユーザー名 / メールアドレス / パスワード)

### 非ユーザ向け (ゲスト向け)
- ログインしていないユーザも曲一覧 / 詳細(コメント)の閲覧可能
- 曲ファイルの 再生 / 停止も可能
- 未ログインユーザが特定の操作(投稿など)をする時にログインを促す
- 曲の タイトル / タグ / 投稿者で検索可能
